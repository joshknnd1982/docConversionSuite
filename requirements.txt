# IMPORTANT: External binaries must be installed separately
# ==============================================================================
# 
# 1. Tesseract OCR (required for 'auto', 'tesseract', and 'ocrmypdf' modes):
#    - Windows: https://github.com/UB-Mannheim/tesseract/wiki
#    - Linux:   sudo apt-get install tesseract-ocr
#    - macOS:   brew install tesseract
#
# 2. OCRmyPDF CLI tool (optional, only for 'ocrmypdf' mode):
#    After installing Tesseract, install via:
#    - pip install ocrmypdf
#    OR use your system package manager
#
# 3. Vision model for picture descriptions (optional): the llama.cpp engine
#    (llama-server) and a model. Download both, checked against published
#    SHA-256 checksums, with:  python -m pdfmd --vision-update
#    or install llama.cpp yourself (winget install llama.cpp, brew install
#    llama.cpp) so llama-server is on the PATH, then run --vision-update for
#    the model.
#
# Note: The pdfmd package will detect and use these tools automatically
#       when available. If not installed, 'off' mode will still work.
